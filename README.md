# Framer static export

Source: https://ali000.framer.website/

This folder is a rendered static export captured from the published Framer site.
It contains 8 discovered routes and 172 downloaded assets.

## Local preview

From the repository root:

```bash
npx sirv-cli framer-export --port 4174 --single
```

Then open <http://localhost:4174/>.

This is a frontend snapshot. Framer editor data, CMS editing, server-side behavior,
form backends, analytics, and other account-level features are not included.
